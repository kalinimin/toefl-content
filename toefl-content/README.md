# toefl-content

Задания для TOEFL-тренажёра. Формат описан в документе «TOEFL-тренажёр: спецификация заданий и шаблоны».

## Как добавить или изменить задание

1. Создайте или отредактируйте JSON-файл в папке секции (`reading/`, `listening/`, `writing/`, `speaking/`).
   Имя файла = `id` задания. При изменении существующего задания увеличьте `version`.
2. Запустите проверку и сборку индекса:

   ```
   python tools/build_index.py
   ```

3. Если ошибок нет, закоммитьте изменения вместе с `index.json` и отправьте на GitHub.
4. В приложении нажмите «Обновить задания».

Задания со `"status": "draft"` в индекс не попадают.

## Аудио

Файлы озвучки лежат в `listening/audio/` и `speaking/audio/`. Скрипт генерации через Azure TTS (`tools/generate_audio.py`) будет добавлен к модулю Listen and Repeat.
